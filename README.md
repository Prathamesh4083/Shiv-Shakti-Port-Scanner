# Shiva-Shakti Port Scanner
###  This multi-threaded desktop security application is designed to identify open ports and analyze network services. It is packaged as a desktop executable file and features a graphical user interface built with Python's Tkinter framework.

### This tool was developed by **Prathamesh Chhabu Chavhan**, a computer science student at Savitribai Phule Pune University, as his **second-year final project**.
